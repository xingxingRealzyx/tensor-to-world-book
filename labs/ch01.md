## 本章实验：让二维投影矩阵真正学会一项变换

第一个实验不从大模型开始，而是训练一张小矩阵和一个偏置。数据生成器提供二维输入 x，以及由固定仿射变换产生的目标 y；训练程序只能看到成对样本，不能直接把目标矩阵复制为参数。模型计算 `y_hat=xW+b`，以预测与目标的逐元素均方误差为损失，反向传播更新 W 与 b。每次训练都要经历取样、前向、计算损失、清空旧梯度、反向和优化器更新，因而这是实质学习，不是观察一张随机矩阵的输出。

在项目根目录、已安装依赖的环境中运行：

```bash
python -m tinyomni.lab --chapter 01 --steps 100 --out runs/ch01
python -m tinyomni.lab --chapter 01 --load runs/ch01/model.pt --predict
```

第一条命令训练并保存参数，第二条在新的推理过程加载 `model.pt`，对实验生成的输入进行预测。命令是读者可以执行的操作说明，是否达到验收要求应以本次输出为准。保存的不是预测答案表，而是学到的参数及恢复实验所需的配置；因此换一组输入，加载后的模型仍应能计算输出。

训练时沿着 shape 检查：输入的最后一维是 2，投影前后保留批次轴，损失则把有效样本和输出分量归约为标量。不要把批次轴放进可学习矩阵，也不要把 `detach` 后的预测拿来计算训练损失，否则看似相同的数字运算将无法把梯度传回 W。

成功标准有三层：损失相对初始化明显下降；未用于更新的输入也获得较小误差；保存后重新加载，对同一输入的预测在浮点容差内一致。只达到第一层，可能只是记住了有限训练点；只比较文件是否存在，也不能证明加载成功。记录初始误差、结束误差和独立输入误差，才能把“程序运行完了”与“学到了变换”区分开。

若损失不降，先检查 x、y 是否配对、目标是否与模型形式相容、W 是否加入优化器；若训练误差低而新输入误差大，检查训练输入是否覆盖两个方向。所有输入都落在同一直线上时，数据无法确定整个二维变换，继续增加相同方向的样本也解决不了这个可辨识性问题。

## 四维实训：训练一个逐像素通道变换器

现在让模型的输入与输出始终保持四维。输入为 `[B,3,H_img,W_img]`，输出为 `[B,2,H_img,W_img]`；每个空间位置取出三个通道的数，交给同一套参数，得到两个新通道。B只区分样本，高宽只区分位置，三者都不进入参数矩阵。第12章会把这个操作展开成1×1卷积图，本节先训练它。

数据生成器使用下面的规则构造目标。这里把取出的三个数记为x0、x1、x2，代表**同一像素的三个通道**，而不是三个相邻像素：

```text
y0 =  1*x0 - 2*x1 + 0.5*x2 + 0.25
y1 = -0.5*x0 + 1*x1 + 2*x2 - 0.75

输入批次        [32,3,4,5]
可学习卷积核    [2,3,1,1]    共6个权重
可学习偏置      [2]          共2个偏置
预测与目标      [32,2,4,5]
逐格平方误差    [32,2,4,5]
所有格的平均值  []           一个loss标量
```

程序中的模型是随机初始化的 `Conv2d(3,2,kernel_size=1)`，只有8个可学习参数。目标生成器知道上面的规则；模型得到的训练信息是成对的输入与目标，通过反向传播拟合参数。B从32换成2、H_img从4换成2，或W_img从5换成4，都不会改变这8个参数。

```bash
python code/fourd_lab.py train --steps 400 --device cpu --out runs/fourd-channels
python code/fourd_lab.py predict --checkpoint runs/fourd-channels/model.pt --input code/fourd-input.json --output runs/fourd-channels/prediction.json --device cpu
```

第一条命令进行400次真实参数更新，并保存模型、优化器状态和逐步误差。第二条命令是独立的命令行推理入口：重新载入学到的权重，读取JSON中的四维 `images` 数组，写出四维结果。推理只接收输入，不调用目标生成器。这就是把已训练的张量变换部署成一个可重复使用的文件接口。使用已安装CUDA版PyTorch的3090时，可将两条命令的设备改为 `cuda`；随书记录实际来自CPU。

`code/fourd-input.json` 正是本章的0到47，形状为 `[2,3,2,4]`。输出应为 `[2,2,2,4]`，共有32个数。第二个样本、最后一个像素的输入通道为 `[31,39,47]`；手算目标是 `[-23.25,116.75]`。随书训练后的模型实际给出约 `[-23.250027,116.750031]`，微小差别来自拟合误差与浮点运算。文件中的数字来自加载后推理，不是把手算目标写进输出。

| 核对项 | 本次CPU运行结果 | 说明 |
| --- | --- | --- |
| 初始验证MSE | 约6.97707 | 尚未更新的随机参数 |
| 400步后验证MSE | 约5.19×10⁻¹³ | 同一独立验证集，形状为 `[64,3,5,7]` |
| 保存前后预测最大差 | 0 | 重新加载仍得到同样结果 |
| 卷积与换轴后矩阵乘法最大差 | 约9.54×10⁻⁷ | 用同一组已学习参数计算 |
| 改动样本1后，样本0输出最大差 | 0 | 样本之间没有被错误混合 |

验证数据使用另一条随机流，并改变了空间尺寸。这个实验要验收的是“学到共享的通道变换，并正确保留四根轴”。目标本来就是仿射函数，所以小模型能达到很低误差；这些结果不表示它会识别照片。训练记录在 `runs/fourd-channels/metrics.json`，模型与预测文件也在同一目录。

**纸笔验收。** 若只把 `X[1,2,1,3]` 从47改为48，其余格不变，哪些输出应变化？先列出地址再算增量。答案是同一样本同一像素的两个输出格：`Y[1,0,1,3]` 加0.5，`Y[1,1,1,3]` 加2；其他输出都不变。若程序使另一个样本也变化，应检查是否把B并入了位置轴；若左右邻点变化，应检查是否误用了大于1的卷积核或沿宽度做了乘法。
